# CodeAlpha_WebScraping

## Objective
Scrape book data from books.toscrape.com using Python and BeautifulSoup.

## Tools Used
- Python
- Requests
- BeautifulSoup
- Pandas

## Dataset
The dataset `books.csv` contains 1000 books with the following columns:
- Title
- Price
- Rating
- Availability
- Product URL

## How to Run
```bash
pip install -r requirements.txt
python scrape_books.py
